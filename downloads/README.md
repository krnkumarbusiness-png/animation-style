# Animate Skill Pack by Karan Kumaar (@krn.tips)

This folder contains the complete Antigravity & Claude Animation Skill file.

## How to Install in Antigravity:
1. Copy the nimate folder into your Antigravity skills directory (~/.gemini/antigravity/builtin/skills/ or your workspace skills).
2. Activate with: /skill animate or reference in prompts.

## How to Use in Claude:
1. Open Claude.ai -> Projects.
2. Under Project Instructions, paste the contents of SKILL.md.
3. Enjoy generating unlimited consistent styles from 1 master prompt!
